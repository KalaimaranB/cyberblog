Cybersecurity 🛡️

Going into cybersecurity was truly a chance event - a couple of my friends mentioned the field and I thought I might explore. I started with a couple intro certs from Google & ISC2 to learn about the field. Penetration testing seemed like a pretty fun job so I looked into learning platforms and TryHackMe stood out. TryHackMe has taught me everything from network structure & intrusion, CI/CD pipeline vulnerabilties to web app pentesting.

Over the past year, I’ve spent many hours working through TryHackeMe’s learning paths and am finally reaching the end of the red teaming pathway. I recently joined the UBC CTF team and will participate in team challenges in the 2025-2026 school eyar. I will continue to learn more about Active Directory and web app exploits so I will be prepared to take the PT1 (Penetration Testing Level 1) certification in 2026.

  4. Pentest report on Wreath - I completed a network room on TryHackMe and wrote a complete pentest report on the results. View it here.
  5. Pentest report on HackSmarter Web App - For the capstone project from HackSmarter’s Web App, I completed a full report independently. View it here.

My long term goal in this field is to gain the skills of a red teamer and eventually specialize in cloud and AI security testing.
